## [1.0.0] - 2025-02-13

### Added
- Initial release of genew4-orm
- SQLAlchemy/SQLModel-based ORM for genew4 PostgreSQL database
- Type-safe models with Pydantic validation
- Automatic audit logging for all write operations
- Read-only and read-write session management
- Query helpers for eager loading and performance optimization
- Comprehensive test suite with unit, integration, and e2e tests
